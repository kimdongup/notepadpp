## 지원 운영체제 (Supported OS Table)

* **OS** 열은 운영체제 목록입니다.
* **실행 가능한 마지막 버전 (last version can be run)** 열은 해당 OS에서 실행될 수 있는 최신 릴리스 상태를 나타냅니다. 최신 버전이 해당 OS에서 정상 동작하는 경우 버전 번호 대신 `현재 버전 (current version)`으로 표시됩니다.
* **지원 여부 (supported)** 열은 Notepad++ 개발 팀이 해당 OS 환경을 공식 지원하는지 여부를 나타냅니다. 공식 지원이 중단된 OS에서만 발생하는 버그는 개발 팀에서 별도로 처리하지 않습니다.

|           운영체제 (OS)          | 실행 가능한 마지막 버전 |      공식 지원 여부       |
|---------------------------------|-----------------------|-------------------------|
| **Windows 95**                  | v3.9                  |          미지원 (No)     |
| **Windows 98**                  | v6.0                  |          미지원 (No)     |
| **Windows ME**                  | v6.0                  |          미지원 (No)     |
| **Windows NT 4.0**              | v4.7.3                |          미지원 (No)     |
| **Windows 2000**                | v6.6.9                |          미지원 (No)     |
| **Windows XP**                  | v7.9.2                |          미지원 (No)     |
| **Windows Server 2003**         | v7.9.2                |          미지원 (No)     |
| **Windows Vista**               | v8.4.6  \*            |          미지원 (No)     |
| **Windows Server 2008**         | v8.4.6  \*            |          미지원 (No)     |
| **Windows 7**                   | 현재 버전              |          미지원 (No)     |
| **Windows 8**                   | 현재 버전              |          미지원 (No)     |
| **Windows 8.1**                 | 현재 버전              |          지원 (Yes)      |
| **Windows 10**                  | 현재 버전              |          지원 (Yes)      |
| **Windows 11**                  | 현재 버전              |          지원 (Yes)      |
| **macOS 10.15+ (Catalina 이상)** | 현재 버전 (Native Cocoa) |         지원 (Yes)      |

\* GCC로 빌드된 Notepad++ 버전은 Vista 및 Server 2008에서 실행 가능합니다.

*각 OS 버전의 최종 서비스 팩(Service Pack) 기준입니다.*
