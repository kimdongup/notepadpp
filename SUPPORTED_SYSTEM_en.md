## Supported Operating Systems Table

* The **OS** column lists the operating systems.
* The **last version can be run** column indicates the latest release that runs on that OS. If the current version runs properly, it is marked as `current version`.
* The **supported** column indicates whether the Notepad++ development team officially maintains and supports that environment.
